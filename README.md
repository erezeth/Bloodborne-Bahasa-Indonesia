# Bloodborne Indonesian Translation (PC Port)

![Status](https://img.shields.io/badge/Status-In_Progress-yellow) ![Platform](https://img.shields.io/badge/Platform-PC_(shadPS4)-blue) ![Region](https://img.shields.io/badge/Region-CUSA03173_(EU)-green)

Selamat datang di repositori mod terjemahan Bahasa Indonesia untuk **Bloodborne (PC Port / shadPS4)**. 

Proyek ini dibuat untuk memberikan pengalaman bermain Bloodborne yang lebih mendalam bagi para Hunter di Indonesia. Terjemahan disesuaikan dengan gaya bahasa *Dark Fantasy*, Gotik, dan *Cosmic Horror* agar tetap setia pada nuansa asli game.

## ✨ Fitur Utama
*   **UI & Menu**: Seluruh menu, pengaturan, dan teks antarmuka diterjemahkan.
*   **Dialog & NPC**: Percakapan dengan NPC dan teks lore diterjemahkan.
*   **Item & Deskripsi**: Deskripsi senjata, alat, dan item diterjemahkan secara puitis.
*   **Pesan Darah (Blood Messages)**: Pesan pemain di lantai diterjemahkan.
*   **Konsistensi Istilah**: Nama Item, *Blood Echoes*, *Insight*, *Hunter's Dream*, *Caryll Runes*, dan nama tempat **sengaja dibiarkan dalam Bahasa Inggris** untuk mempertahankan identitas asli dan *feel* Bloodborne.

## ⚠️ Kompatibilitas
*   **Game**: Bloodborne PC Port (shadPS4 / BBLauncher).
*   **Region**: Diuji pada region **CUSA03173 (Europe / GOTY Edition)**.
*   **Pengaturan Bahasa**: Di dalam game, pastikan pengaturan bahasa disetel ke **English (UK)** atau **English (US)** (tergantung folder yang kamu timpa).

## 📥 Cara Instalasi
1. Unduh file `.zip` terbaru di tab **[Releases](../../releases)** sebelah kanan.
2. Ekstrak file tersebut.
3. **⚠️ WAJIB BACKUP**: Salin (copy) folder `msg` asli dari game kamu ke tempat yang aman sebelum menimpa file apa pun.
4. Buka folder hasil ekstrakan. Kamu akan melihat folder `CUSA03173`.
5. Copy folder `msg` (atau folder `enggb` / `engus` di dalamnya) dan tempel ke direktori game kamu:
